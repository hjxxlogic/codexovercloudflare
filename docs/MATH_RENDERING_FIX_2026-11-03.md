# OpenAI 多行公式修复 · 2026-11-03

## 复现与修复

通过现有登录身份只读获取用户指定会话快照。最新助手消息包含 17 个 `\(...\)` 行内公式和 16 个 `\[...\]` 块公式。旧实现仅在 Markdown 行内解析阶段处理 OpenAI 分隔符；块解析阶段先把独立 `=` 识别为标题分隔符，导致其中 5 个块公式拆开。行内公式本身均能解析。

新增有界块级 tokenizer，在 Markdown 标题解析前保护独立行开启的显示公式。公式关闭后的正文继续原生解析强调、链接与行内公式；TeX 双反斜杠及换行间距保持，引用 / 列表不能跨出容器捕获。代码、转义分隔符、未闭合和超限内容保留普通 Markdown 回退。原始消息、会话凭据与截图只保存在 ignored `.local/inline-math-2026-11-03/`，不复制到公共测试或文档。
