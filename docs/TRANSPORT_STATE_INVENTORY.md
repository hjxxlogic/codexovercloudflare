# 传输状态与资源

## 状态归属

| 状态                                 | 权威位置                 | 生命周期                               |
| ------------------------------------ | ------------------------ | -------------------------------------- |
| 身份、邮箱、授权、撤销事件、主机目录 | RegistryDO               | 原生 DO 持久状态，授权变更触发失效事件 |
| 租约、控制代际、ticket、项目写资格   | Agent SQLite             | 持久控制状态与有界到期索引             |
| 业务请求、命令、结果、信用、历史订阅 | Agent / 客户端           | 执行端与发送端日志，端到端确认         |
| 连接路由、密文处理队列               | Worker attachment / 内存 | 有界尽力转发，重建允许丢失             |
| 会话、历史投影、正文和恢复元数据     | Agent SQLite             | 一周及容量策略，活动任务受保护         |
| 已读取页面、草稿、原请求             | CW IndexedDB / CC SQLite | 缓存与可靠待办分别计量，确认后回收     |
| 项目登记                             | `dataDir/projects.json`  | 原子替换及单调 revision                |
| Terminal 输入、输出、seq、offset     | Agent / 浏览器内存       | 易失 runtime，不承担持久业务交付       |

Worker 不保存业务 ACK、补发日志或正文回放。权限事务回执不能代替业务完成；配置正文仅在端点解密，中继只转发密文，不进入 DO 或日志。

旧 HostRelayDO 首次访问迁移会暂存 `~opaque-v1:backup:*` 与事务游标，保留 `wakeUntil`，完成后取消旧 alarm。此隔离备份只用于发布窗口导出与核对，不参与新业务路由、控制权或重放；活动旧租约、未完成权限操作及未知迁移版本均阻止新业务。RegistryDO 的身份、授权、撤销 / 到期和失效重试记录保持原结构。具体迁移与备份处置见 [发布操作](RELEASE.md#不透明中继的状态迁移准备)。

## 主要预算

以下为默认逻辑预算，具体定义见 `native/include/coc/credit.hpp`；历史预算还可由 Agent JSON 收紧或调整。预算包含记录和封装开销，不等于 RSS、SQLite 文件或安装目录硬配额。

| 资源                     | 边界                                                                                    |
| ------------------------ | --------------------------------------------------------------------------------------- |
| Agent normal 命令/结果   | 全局 512 MiB，单会话 128 MiB                                                            |
| Agent priority 命令/结果 | 全局 256 MiB，单会话 64 MiB                                                             |
| Agent 流 / 每流身份      | 各 1024                                                                                 |
| CC 命令/结果             | 每份 32 MiB，全局 512 MiB                                                               |
| CW 命令/结果             | 同浏览器同站点全局 512 MiB；未决交付保留 32 MiB，已完成记录按实际占用                   |
| CC 输出                  | 每份 8 MiB，全局 128 MiB；以 TUI 连续消费位置推进信用                                   |
| 客户端普通缓存           | 全局 64 MiB，单范围 16 MiB；最多 100000 / 10000 条                                      |
| Agent 历史               | 全局 256 MiB / 单会话 64 MiB，250000 / 64000 条，1024 个非空作用域                      |
| Agent 未确认 RPC 输出    | 全局 64 MiB，单会话 8 MiB                                                               |
| Agent HTTP 原请求        | 全局 128 MiB，主体 32 MiB，1024 身份                                                    |
| 上传                     | 全局 96 MiB，最多 4 个 active / 主体 2 个，单文件 20 MiB                                |
| 项目账本                 | 包含替换副本 16 MiB，1024 身份；结果尾部 16 项 / 4 MiB                                  |
| 配置管理                 | 每实例 256 身份，每项 8192 字节；配置原文最多 64 KiB                                    |
| Codex 进程               | 16 个运行会话进程，4 个历史读取进程                                                     |
| 待决审批                 | 单会话 32 项，全局 128 项，另有限字节和线编码上限                                       |
| 网络与本地 RPC           | 网络单帧 256 KiB；本地 Codex RPC 缓冲约 8 MiB                                           |
| Terminal                 | 最多 4 个 runtime、每项目 1 个活跃；输入最多 4 KiB，尾部缓存 256 KiB，未渲染输出 64 KiB |

Worker 无业务请求关联或业务权限事务，只有连接路由和权限失效记录。每 Host 最多 256 条连接，密文单帧 256 KiB，处理中队列同时限制 1024 条 / 8 MiB。端点单消息 8 MiB、分片 64 KiB，待握手队列 1024 条 / 8 MiB，并发请求与单 link 逻辑流各 128；原生复用有界网络发送队列，网页检查 bufferedAmount。过载关闭连接，原请求由端点恢复；密文加密开销计入网络预算。

## 释放与满额处理

信用在公告前持久预留，未确认结果继续占用；normal 不能借用 priority / 恢复保留。结果确认和历史确认独立，确认结果不代表删除历史。来源正文可验证恢复与防重放证据分别回收。

Agent 历史和遗留积压默认一周，80% 水位触发、60% 为清理目标；活动任务和必要预留不驱逐。清理与准入代次/单调屏障同事务提交，旧编号缺失后拒绝重新执行。详见 [数据保留](HISTORY_STORAGE.md)。

预算满时拒绝新副作用或停止相应输出 runtime，并明确标记不完整；不虚报确认。外部观察同步背压保留分页位置，不停止原 Codex。磁盘或 I/O 故障独立于逻辑预算处理。

测试入口见 [测试说明](TEST_REPORT.md)，协议见 [可靠传输](RELIABLE_TRANSPORT.md)。
