## 工程、运维与发布

- 职责拆出 WorkspaceHeader、ApprovalQueue、ConversationView、SessionHistory，HistoryCache 显式 close/versionchange、升级版本和按身份有界修剪；Agent 网络循环与串行业务执行隔离。尚未一次性将所有状态改成 reducer 或拆分全部 Agent 服务。
- 仓库 CI 增加格式/类型/协议、构建、CTest/Vitest、TLS、备份、发布来源、Wrangler/Chromium 和 ASan/UBSan 门禁；Clang 可构建 libFuzzer 入口。首次远端 Actions 的依赖安装失败，隔离安装复现及原因见测试记录，不能算作通过。
- 二进制嵌入版本/提交/源码摘要/目标/协议能力；打包拒绝脏源码、旧二进制及不匹配产物。来源回归覆盖匹配、未跟踪文件和陈旧提交。网页重建保留下载目录并清除陈旧静态资源。校验和与源码摘要不等于签名或第三方构建证明，尚无签名发布链。
- 备份工具使用 SQLite 在线备份，权限 0600；恢复须取得 Agent 实例锁并检查完整性。不恢复模型进程、工作区或 Codex home。备份/恢复回归已通过；生产升级回滚与灾难恢复尚未演练。
- 用户手册、架构、需求、开发、发布和测试记录同步更新，历史发布证据保留并标明时间线。

## 验证范围

完整端到端采用真实 C++ Agent/Client、Wrangler/DO 与 Chromium，Codex 为确定性夹具；独立 UI 压力场景使用合成 API/WS。宿主 Ubuntu 20.04 与 Bookworm 容器分别构建，避免动态库混用。当前常规门禁、42 项 Vitest、完整端到端、UI 压力、TLS、备份、发布来源、doctor 与真实 Codex 无模型协议检查均通过；ASan/UBSan 重建后通过，首次异常和未定位原因保留在测试报告。具体命令、结果和截图见 [测试记录](TEST_REPORT.md)。

暂不将下列建议标为完成验收：四会话八小时与网络心跳延迟、真实 Cloudflare 休眠/升级/回滚、磁盘耗尽/强制掉电、全部 CLI 观察故障、Firefox/WebKit、真机键盘和屏幕阅读器。第三阶段的附件、全文检索、组织账户、跨模式切换及端到端加密属于另行设计的功能方向，不作为本轮可靠性修复交付。
