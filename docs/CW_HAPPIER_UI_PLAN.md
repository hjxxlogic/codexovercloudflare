# CW 界面结构与来源

全站使用 Happier 风格的 React DOM 工作区；会话、审批、文件、模型、Terminal 和可靠传输接入 CoC 原有业务。来源及 MIT 许可证固定在 [上游来源](../apps/web/src/happier/SOURCE.md)，不引入上游服务或第二套会话状态。

## 导航与工作区

左栏按主机、项目、会话三级互斥展开，上级有效才解锁下级；选择上级清空失效的下级，已有有效工作区可在刷新后恢复。授权放在主机列表下，项目新建与刷新放在项目列表下，会话搜索、分页、继续与新建放在会话层。折叠导航、切换设置不结束任务，不销毁 Terminal。

桌面左栏可收起，手机使用可 Escape 关闭的原生抽屉并恢复焦点；选中会话后关闭。设置集中主题、语言、版本、模式和尺寸偏好，管理九个分类沿同一导航切换。纯图标操作保留可访问名称和悬停 / 键盘提示，危险操作保留明确确认。

右上文件、Terminal、输出、刷新和信息复用现有回调。文件树与内容预览分别保存宽度和关闭状态，手机在列表与预览间切换；传输期间锁定目标，隐藏面板保留传输。信息使用模态对话框，长正文独立滚动。正常连接不显示额外连接操作，短暂断线自动恢复；其他页面占用时，继续前明确确认转移控制权。只读历史补读独立于控制连接，不自动抢占。

输入区支持发送、停止、持久队列和原会话自动审批。消息复制保留原始 Markdown，分页正文读全后才提示复制成功；复制控件与反馈浮动，不改变正文高度。主题与密度变化不重连会话或重建 Terminal。

完整操作见 [用户手册](USER_GUIDE.md)，组件边界见 [技术架构](ARCHITECTURE.md)，当前验证见 [测试说明](TEST_REPORT.md)。

## 验证与证据

`test:ui` / `test:ui:navigation` 使用加密模拟接收端检查导航、继续与转移确认、只读补读、复制、文件预览、桌面和三种手机尺寸、主题及管理分类。`test:markdown` 检查富文本，`test:opaque` 使用真实 Worker / Agent / Chromium 检查加密业务与队列，完整 E2E 单独验证真实 PTY。
