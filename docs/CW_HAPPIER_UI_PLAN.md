# CW 的 Happier 界面移植计划与实施记录

## 目标和约束

将 Happier 的会话工作区用于 CoC 的 CW：桌面上提供常驻会话侧栏、清晰的会话标题与状态、集中阅读区和底部输入卡片，手机上侧栏收起且会话入口始终可达。会话、审批、文件、模型、终端和重连继续使用现有功能；本次不部署，也不改 Worker、Agent、协议或权限语义。

工作在 `docs/opaque-relay-architecture` 的隔离 worktree，先单独完成 master 合并提交，再实施网页移植。master 未提交文件和既有线上实例不参与修改。

## 上游来源与移植方法

上游：https://github.com/happier-dev/happier 。固定调研版本 `d515b5547a1a3aa03e3141ddb6a45f4a72ae1025`，采用该版本的 MIT 许可，保留完整许可及版权声明。

提取范围为 `apps/ui/sources` 中 `components/sessions/shell/{SessionView,SessionsList,SessionItem}.tsx`、`components/navigation/shell/SidebarView.tsx`、`components/sessions/agentInput/AgentInput.tsx` 和 `theme/tokens/surfaceAndTextColors.ts`。移植会话列表与内容区分栏、行选中态、标题和状态层级、输入框的卡片与工具栏分层，以及语义颜色。上游为 React Native / Expo Web，组件耦合其同步、路由和存储；将这些界面结构及样式改写为项目的 React DOM 组件，接入现有回调，不引入 Expo、上游服务、同步层或第二套会话状态。不复制上游不被本项目支持的功能入口，也不使用上游品牌标识冒充 Happier。

## 实施步骤

1. 来源固定：记录上游提交、对应文件、MIT 许可和移植映射。
2. 会话外壳：新增独立 Web 组件和限定作用域的样式。侧栏读取现有会话列表，选中调用既有会话连接；新建、历史、文件及详情复用现有入口。桌面宽度足够时显示侧栏，手机使用可关闭抽屉，支持键盘和焦点恢复。
3. 视图接入：CW 对话使用新的会话栏和顶部标题，保留已有消息滚动容器、消息渲染、输入提交处理、未确认提示和审批组件。管理页和登录页不套用会话布局。
4. 视觉移植：使用上游主题语义、间距、边框和卡片层级，适配已有深浅色设置、工作区文件 / 预览 / Terminal 面板及窄屏。优先复用已有渲染，不另造业务 adapter。
5. 验证：类型、lint、网页构建；浏览器验证选择与切换会话、新建 / 历史入口、提示词流式回复、刷新恢复、模型与文件入口、审批、手机抽屉和横向溢出；确保未新增 API、未重复提交任务。
6. 记录：本文件填写实际完成项、偏差、命令结果及截图路径；更新用户手册、文档索引和 CHANGELOG，列出未验证边界。

## 验收标准

- CW 会话呈现 Happier 的侧栏 / 阅读区 / 输入卡片结构，实际操作使用 CoC 已有数据与行为。
- 现有请求去重、控制权、审批和断线恢复行为保留；不在显示组件发起新业务请求。
- 桌面及 390px 手机视口可用，没有全页横向溢出；对话滚动与输入区域不互相遮挡。
- 所有产品改动仅位于 `apps/web/`；相关测试与文档可在对应目录修改，Worker、Agent 和协议在本次网页提交中无差异。
