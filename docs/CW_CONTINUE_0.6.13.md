# CW 0.6.13 继续对话与连接提示

2026-11-06，用户确认交互方案后实施。范围为 Web、Web 验证、版本元数据和文档，继续使用原有 attach / takeover / 线程恢复接口。

## 实施过程

1. 核对原界面：信息中始终并列“重新连接”和“接管控制权”，历史恢复需要寻找另一入口；非 ready 状态统一写“会话已结束”。
2. 统一“继续对话”：历史 closed / failed 状态在正文下方与信息中均提供入口，复用原线程继续；左栏和欢迎页文案同步。starting / closing 显示启动 / 结束等待，不展示继续按钮。
3. 连接正常时隐藏额外连接操作，短暂断线沿原机制自动重试，浮动显示“连接中…”及“重试连接”。可恢复的连接故障由连接提示承载，恢复后消失；认证与权限错误继续保留处理提示。
4. 遇到 SESSION_BUSY / STALE_CONTROLLER 或当前连接被其他端替换，明确显示正在其他页面使用。点击“继续对话”确认“是否转到当前页面？原页面将无法继续操作。”，接受才调用原 takeover 接口；取消不发请求。转移成功后的自动重连改走普通 attach，不重复转移；未确认请求继续按原身份核对，不创建新会话或重发任务。项目写资格冲突仍按原“获取写权限”规则处理。

## Web 验证

`npm run build:web`、`npm run typecheck`、受影响文件 ESLint / Prettier，以及 `npm run test:ui:navigation`。新增占用提示与继续入口、确认取消零转移 / 接受一次转移、正常连接隐藏旧操作、临时断线自动重试 / 恢复消失、四种生命周期状态的按钮和说明检查；同时保留桌面和三种手机尺寸、主题、文件 / 预览、草稿 / Terminal 保留、管理界面检查。

测试为模拟 Web 会话，不运行模型或真实 Shell。线程继续沿用原创建 / 恢复流程，本次未做真实会话恢复任务测试；线上只做 Web 验收，不创建 / attach 会话，结束撤销临时凭据。不执行完整仓库、原生或完整 CI。
