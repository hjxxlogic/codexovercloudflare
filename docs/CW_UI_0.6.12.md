# CW 0.6.12 独立预览与消息复制

2026-11-06，按讨论后的“编码测试发布”实施。修改范围为 Web、Web 验证、版本元数据和文档；沿用原有 Worker / Agent 业务接口。

## 实施

- 正常会话顶栏只保留导航入口与右上五个操作，不显示项目名、会话标题和连接状态。离线 / 重连提示浮动于内容之上，不改变聊天尺寸；恢复后自动消失。认证 / 权限异常保留可见错误与原处理入口，直至处理或主动关闭。
- 文件浏览器与内容预览拆为独立控件，分别保存宽度，分别关闭 / 全屏；关闭浏览器保留预览与进行中的传输，关闭预览保留树的展开、筛选与位置。桌面并排，手机同一时刻显示一个，预览提供返回列表按钮；切换命令输出暂时隐藏预览。传输期间原目标锁定规则继续生效。
- 用户消息与 AI 回复都提供整条复制，AI 复制原始 Markdown。长消息复用现有正文分页读取，读完整后写入剪贴板；并发读取合并，修订变化、读取失败或超时明确失败，不误报已复制。
- 复制按钮浮动在消息 / 工具内容内，默认隐藏，悬停 / 点击 / 键盘聚焦后显示；正文高度不因按钮或反馈改变。代码 / 表格独立复制保留，反馈短暂浮动；现有文件面板复制保持可见。

## Web 验证

- `npm run build:web`、`npm run typecheck`、受影响文件 ESLint / Prettier。
- `npm run test:ui:navigation`：正常顶栏无标题 / 状态、异常浮动且不改变聊天尺寸、恢复自动消失；用户原文 / AI Markdown 复制、超过 13 万字符的分页全文复制、按钮隐藏 / 悬停 / 聚焦与正文尺寸不变；浏览器 / 预览独立关闭、筛选保留、全屏操作；390×844、320×568、844×390 下列表 / 预览 / 返回；回归原三级导航、草稿 / Terminal 保留、设置及管理界面，无浏览器异常。
- `npm run test:markdown`：富文本、代码、表格 TSV、全屏、局部滚动及预览回归。

测试使用模拟业务 / 剪贴板，未启动真实 Shell 或模型任务。线上仍通过 `scripts/verify-web-navigation.ts` 检查 Web，只读既有测试主机并撤销临时 Web 凭据，不创建 / attach 会话。本次不执行完整仓库、原生或完整 CI。
