# DO 唯一存储路径清理 · 2026-11-03

状态：本机工作区已实现，未推送、未部署。当前唯一支持原生 Durable Objects；本记录取代旧文档中的 D1 / legacy 兼容及迁移操作说明，历史证据保留。

## 实现范围

- Registry 统一经 RegistryDO，授权、邮箱、目录和撤销失效事件使用所属 DO 原生存储；移除 D1 直读及可注入的另一套状态存储。
- HostRelayDO 原地保存租约、epoch、ticket 与权限事务。移除 HostLifecycle、presence 副本、空闲归档、跨库权威切换及离线 D1 回执读取 / 确认。
- 删除 D1State、迁移模块、SQL schema、后台回收 Cron handler、管理员迁移路由及迁移健康查询。健康接口仅保留普通健康行为，旧查询参数不再读取迁移状态。
- Env 及根配置移除后端选择与数据库绑定；保留既有 RegistryDO / HostRelayDO namespace 和 `v1` SQLite class migration，现有对象及数据继续使用。
- 开发、原生 / Chromium E2E、项目 E2E 与 CI 统一使用 DO。删除旧后端专用入口、迁移测试、工具及制品中的 SQL schema。
- 部署工具删除数据库选择、迁移及退役参数，不再执行远端 SQL；拒绝含旧后端选择变量、数据库绑定或错误 DO 类绑定的制品。保留准确提交的 CI、制品摘要、源码身份及下载站保全检查。

仅用于拒绝旧配置的部署检查及其反例测试仍包含旧配置键名；它们不能选择、创建或访问旧后端。原生客户端 / Codex 协议兼容、旧邮箱授权关联和 DO 内已有到期记录索引补齐与后端无关，保持现有行为。

## 数据和运行行为

不删除或导入数据库，不重置 DO，不改写 namespace，旧迁移标记不参与路由。现有 DO 中的授权、租约、epoch 和权限回执继续使用。独立部署若仍依赖旧数据库，应先使用此前迁移版本完成迁移，再升级本版本；当前版本不再承担迁移。

保留有限期记录的 DO 到期索引及一次性 alarm；没有数据到期时不增加周期维护。业务恢复由端点日志负责。连接授权规则见 [连接授权契约](WORKER_CONNECTION_AUTHORIZATION.md)。

## 验证

本机验证结果见 [测试报告](TEST_REPORT.md)。覆盖完整目录分页、有限到期分页与无周期 alarm、原生 DO 授权和控制状态跨重建保留、授权变更重试、权限回执、控制接管及原生 / 浏览器终端链路。不将本机验证视为 CI 或线上发布证据。
